# Loki's Diner

A simple diner ordering app built with HTML, CSS and JavaScript.

## Features

- Add items to an order
- Remove items from an order
- Calculate the total price
- Complete an order with a simple payment form
- Show an order confirmation message

## Built With

- HTML
- CSS
- JavaScript

## What I Practiced

- DOM manipulation
- Event delegation
- JavaScript modules
- Arrays and objects
- FormData
- Managing state and re-rendering the UI
